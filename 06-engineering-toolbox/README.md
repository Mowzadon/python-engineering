# Engineering Toolbox

A command-line Python application for managing an engineering toolbox inventory.

## Features

- View inventory
- Add new tools
- Use tools (decrease quantity)
- Repair tools
- Move tools to a new location
- Remove tools
- Display inventory statistics
- Save inventory to a JSON file
- Load inventory from a JSON file

## Concepts Practiced

- Object-Oriented Programming (Classes & Objects)
- Methods and helper functions
- Lists of objects
- Searching algorithms
- JSON file storage
- Reading and writing files
- Input validation
- Multi-file Python projects
